# راهنمای انتشار نسخه جدید (Release Guide)

این مستند راهنمای انتشار نسخه‌های جدید نرم‌افزار **Online Subtitle Generator** در گیت‌هاب (GitHub Releases) می‌باشد.

---

## ۱. ویژگی‌های نسخه خروجی و پکیجینگ
هنگام ساخت نسخه نهایی، عملیات زیر به صورت کاملاً خودکار انجام می‌شود:
- **اجرای تست‌ها:** اعتبارسنجی خودکار تست‌های واحد و یکپارچه با `pytest`.
- **کامپایل سورس کد:** کامپایل کد پایتون به باینری مستقل با استفاده از PyInstaller و فایل کانفیگ بهینه‌شده `OnlineSubtitleGenerator.spec`.
- **بسته‌بندی نیازمندی‌ها (FFmpeg و FFprobe):** فایل‌های اجرایی استاتیک `ffmpeg.exe` و `ffprobe.exe` به همراه تمام دارایی‌ها (`assets/`)، آیکون‌ها و فایل حالت پرتابل (`portable.txt`) در پوشه خروجی قرار می‌گیرند.
- **ایجاد آرشیو فشرده پرتابل:** پوشه خروجی به صورت فایل فشرده با نام `Online-Subtitle-Generator-<TAG>-Windows-Portable.zip` بسته‌بندی می‌شود.
- **تولید چکسام SHA-256:** برای اعتبارسنجی سلامت فایل فشرده، فایل `.sha256` هم‌نام به صورت خودکار ایجاد می‌گردد.

## ۲. روش‌های انتشار نسخه جدید

### روش اول: اجرای با یک کلیک با اسکریپت Release (توصیه‌شده برای ویندوز)
1. روی فایل `release.bat` در ریشه پروژه دابل‌کلیک کنید (یا دستور زیر را در ترمینال اجرا کنید):
   ```bash
   python scripts/publish_release.py
   ```
2. اسکریپت به صورت خودکار آخرین تگ گیت‌هاب را شناسایی کرده و تگ نسخه بعدی (مثلاً `v1.0.10`) را پیشنهاد می‌دهد.
3. در صورت تایید، تست‌ها اجرا شده، برنامه کامپایل و بسته‌بندی می‌شود، تگ گیت ایجاد و به گیت‌هاب پوش (Push) می‌گردد.
4. **نکته انتشار مستقیم:** اگر متغیر محیطی `GITHUB_TOKEN` را تنظیم کنید یا از فلگ `--token <YOUR_TOKEN>` استفاده کنید، انتشار ریلیز و آپلود فایل zip مستقیماً توسط اسکریپت در صفحه Releases گیت‌هاب انجام می‌شود.

#### پارامترهای پیشرفته:
```bash
# بیلد و ایجاد تگ بدون اجرای مجدد تست‌ها
python scripts/publish_release.py --tag v1.0.10 --skip-tests

# پوش مستقیم تگ به مخزن جهت فعال‌سازی اکشن
python scripts/publish_release.py --tag v1.0.10 --push
```

---

### روش دوم: انتشار ابری از طریق GitHub Actions (توصیه‌شده و بدون نیاز به سیستم لوکال)
مخزن دارای ورک‌فلو خودکار `.github/workflows/release.yml` است که روی سرورهای ابری ویندوز مایکروسافت اجرا می‌شود:

1. وارد صفحه ریپازیتوری در گیت‌هاب شوید:
   `https://github.com/AliDevCore/Online-Subtitle-Generator`
2. به تب **Actions** بروید.
3. از منوی سمت چپ، ورک‌فلو **Build and Release Windows Executable** را انتخاب کنید.
4. دکمه **Run workflow** را بزنید:
   - در فیلد `Release Tag` می‌توانید تگ دلخواه (مثل `v1.0.10`) را وارد کنید یا خالی بگذارید تا خودکار ایجاد شود.
   - دکمه سبز رنگ **Run workflow** را کلیک کنید.
5. سرور ابری گیت‌هاب تمام مراحل تست، بیلد، دانلود FFmpeg، ساخت zip پرتابل و انتشار در بخش Releases را به صورت خودکار انجام می‌دهد.

---

### روش سوم: انتشار از طریق تگ Git در ترمینال
با ایجاد و ارسال هر تگ استاندارد نسخه، بیلد ابری به طور خودکار استارت می‌خورد:
```bash
git tag -a v1.0.10 -m "Release v1.0.10"
git push origin v1.0.10
```
